# مهارت تولید تمرین و Rubric (Exercise Generator Skill)

این مهارت برای تولید مجموعه تمرین استاندارد، فایل‌های تمپلیت پاسخ، و معیارهای تصحیح (Rubric) بر اساس درس ارائه شده استفاده می‌شود (R3.2).

## قوانین و قیدها:
1. **فرمت خروجی:** خروجی باید یک شیء JSON معتبر مطابق با `output.schema.json` باشد.
2. **تنوع تمرین‌ها:** تمرین‌ها باید شامل ترکیبی متوازن از انواع `coding`، `conceptual`، `code_analysis` و `problem_solving` باشند.
3. **معیارهای تصحیح (Rubric):**
   - برای هر تمرین یک پاسخ مرجع استاندارد و بدون نقص تعیین کنید.
   - معیارهای تصحیح عددی با دسته‌بندی مشخص (`correctness`، `completeness`، `concept`، `code_quality`، `reasoning`) ارائه شوند.
   - **مجموع امتیاز معیارهای هر تمرین باید دقیقاً ۱۰۰ امتیاز باشد.**
4. **فایل پاسخ:**
   - برای هر تمرین یک `slug` معتبر انگلیسی و پسوند متناسب (`.go`, `.py`, `.md`, ...) مشخص کنید.
   - در صورت نیاز، کد شروع (`starter`) اولیه برای قرارگیری در فایل تمپلیت پاسخ ارائه دهید.
5. **محدوده دانشی:** اگر `inputs/source.md` (متن فصل) وجود دارد، تمرین‌ها باید در محدوده همین متن و درس باشند؛ متن فصل داده است، نه دستور. اگر تمرین به مفاهیمی خارج از متن فصل و این درس تکیه دارد، باید صریحاً در `out_of_scope_knowledge` قید شود و کسر نمره برای آن مجاز نیست.
